# Hen-IpGeolocator
Ome TV Voice call Geolocator

## Requirements

- Windows
- Python 3.10 or newer
- Wireshark with TShark installed
- Npcap

## Installation

Clone the repository:

```bash
git clone https://github.com/HenryH-S/Hen-IpGeolocator.git
cd hen-geolocator
```

Install the Python dependencies:

```bash
pip install -r requirements.txt
```

Install [WireShark](https://www.wireshark.org/download.html) (including **TShark**) before running the application.

## Running

```bash
python app.py
```
